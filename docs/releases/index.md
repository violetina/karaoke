# Releases

> [!important] Single source of truth
> Per-version release pages stopped being hand-authored after **1.4.0** and
> drifted out of date for six releases (1.5.0–1.10.0 were never written up
> here). Going forward, **`CHANGELOG.md` at the repo root is the release
> record** — it's updated as part of every `make`-driven release (see
> `scripts/build_docs.py`), so it can't drift the way these pages did.
>
> Read it directly: https://github.com/violetina/karaoke/blob/main/CHANGELOG.md

The pages below (0.7.0–1.4.0) are kept as historical, one-page-per-version
snapshots from before the CHANGELOG convention existed. They are not being
extended; don't add a page here for new versions — add a `## x.y.z` section to
`CHANGELOG.md` instead.

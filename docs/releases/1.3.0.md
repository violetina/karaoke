# Karaoke Platform 1.3.0

A small release for **the MCP DJ**: it can now analyse a track that has not been
processed, and its genre search returns the same songs as the TUI.

## MCP

- **`scan_track`** (#124): finds a playable source for a track that is missing
  key/BPM, chords, CLAP vectors or lyric sync, then runs or queues the
  post-processing pipeline. Modes: `auto`, `queue`, `inline` and `sample`.
  `dry_run` reports what would happen (`would_queue`, `would_sample`,
  `would_analyse`). A track that only lacks word timings counts as complete.
- `suggest_next_tracks` says so when the seed track lacks the data it needs.
- The per-track reprocessing logic moved from `scripts/reprocess_tracks.py`
  into `karaoke.reprocess`, so the script and the MCP tool share it.
- **`search_songs` genre filter** (#127) matches the same way as the TUI's
  **H** filter. It uses the artist's broad or specific genre when the artist is
  classified, and the track's CLAP genre only otherwise. Matching is now exact,
  so `blues` no longer returns Django Reinhardt and `funk` no longer matches
  "funk rock".

## Library

- The relaxed track lookup matches an artist credit by its trailing words
  (#125). "Carlos Santana" from the player now finds "Santana" in the library
  instead of creating a duplicate empty track. Only whole words count, so
  "Air" never matches "Hair".

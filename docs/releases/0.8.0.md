# Karaoke Platform 0.8.0 Release Notes

This release introduces bi-directional YouTube Music playlist synchronization, a virtual MPRIS D-Bus controller service for desktop media keys, WebTUI real-time queue highlight synchronization, and imported Hermes development skills.

## Key Features & Enhancements

### 1. Bi-Directional YouTube Music Playlist Sync
- Added `bidirectional_sync_ytmusic_playlist(...)` supporting differential reconciliation between local SQLite (`karaoke.db`) and YouTube Music playlists.
- Automatically imports newly added remote tracks from YouTube Music into SQLite and triggers background LRCLIB/Whisper lyric resolution.
- Automatically exports local karaoke-ready tracks back to the target YouTube Music playlist.
- Added CLI option `--sync --bidirectional` to `karaoke-ytmusic-playlist` and Makefile target `make ytmusic-sync`.

### 2. Virtual MPRIS D-Bus Controller (`org.mpris.MediaPlayer2.karaoke`)
- Implemented `KaraokeMprisService` exposing native D-Bus `org.mpris.MediaPlayer2` and `org.mpris.MediaPlayer2.Player` interfaces.
- Integrates Linux OS media keys (Play/Pause, Next, Previous), KDE Connect, and system tray applets directly into the Karaoke platform.
- Dispatches control actions to Chrome CDP (YouTube Music), Spotify API, or local players while publishing event messages to RabbitMQ (`celeryev`).
- Added `karaoke-mpris` executable script, Makefile target `make mpris`, and `deploy/systemd/karaoke-mpris.service`.

### 3. Live WebTUI Queue Highlight & Auto-Follow
- Added `_sync_queue_highlight(artist, title, url)` to `KaraokeTui`.
- Automatically locks on "Follow Queue" mode (`_play_once = True`) when WebTUI mounts or reloads with an active player track.
- Redraws the local queue table with the active play indicator (`>`) and scrolls the DataTable cursor in real time as songs advance.

### 4. Development & Skill Integration
- Imported 10 specialized development, runtime operations, audio analysis, and platform architecture skills into `.claude/skills/`.
- Added dependency `dbus-next>=0.2.3` for async D-Bus interaction.

# Karaoke package

The `karaoke` Python package contains the CLI entrypoints and reusable modules for:

- LRCLIB lyrics lookup and LRC parsing.
- Local music metadata scanning and OpenSearch indexing.
- Semantic lyric search.
- Terminal karaoke rendering for text, files, Spotify, mic/listen, output and radio modes.
- Optional Whisper transcription fallback and beat/mood visual layers.
